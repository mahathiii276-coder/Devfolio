# Mahathi's Developer Portfolio

A clean, modern, and responsive personal portfolio website built with plain
HTML and CSS. It introduces Mahathi, a first-year B.Tech student, and
showcases a few beginner projects along with contact details.

## Features

- Semantic HTML structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive layout using Flexbox (header/navigation) and CSS Grid (project cards)
- Mobile-friendly: 1-column project grid on small screens, 3 columns on
  desktop (`@media (min-width: 700px)`)
- Simple color system and consistent typography using CSS variables
- Hover effects on navigation links and project cards
- No frameworks or JavaScript — just HTML and CSS

## How to Run Locally

1. Download or clone this project folder.
2. Open `index.html` directly in any web browser (double-click the file, or
   right-click → "Open with" your browser of choice).

No build tools, installation, or server setup is required.

## Customization

- Update the bio text in the **About** section of `index.html`.
- Replace the placeholder project titles, descriptions, and links in the
  **Projects** section with your own work.
- Update the Email, GitHub, and LinkedIn links in the **Contact** footer.
- Adjust colors and fonts by editing the CSS variables at the top of
  `style.css`.
